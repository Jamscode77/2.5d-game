================================================================================
  VEIL OPS — BEGINNER GUIDE (Godot 4)
================================================================================

1. Install Godot 4.3+ from https://godotengine.org
2. Godot → Import → select this folder (project.godot)
3. Press F5 (Play). Main scene should be scenes/main.tscn

OVERWORLD (little sprites)
--------------------------
  WASD                    walk the operative sprite
  Walk near a map pin     see interact hint
  E / LMB                 accept mission brief
  RMB                     enter 3D combat (hostile / mission pins)

COMBAT (3D models + action points)
----------------------------------
  Each turn you get AP (Operative: 6). Enemies get their own AP too.
  Actions spend AP; RMB ends the turn early. At 0 AP the turn ends.

  WASD                    move (burns ~1 AP per 1.25m; leaves cover)
  Mouse                   look / aim (reticle)
  LMB                     shoot under reticle (−2 AP, uses ammo)
  R                       reload magazine (−2 AP)
  Q                       Focus skill (−3 AP, next shot +2 dmg)
  F                       Field Stim gear (−2 AP, heal)
  C                       take / leave cover (−1 AP to take)
  RMB                     end turn
  Esc                     free mouse cursor

  Cover: crates/walls on the arena. Half ≈ 50% soak from the front;
  Heavy/Full soak more. Walk around to flank and ignore their cover.

WHAT YOU SHOULD SEE
-------------------
- Sprite overworld with red/blue pins and a walkable operative
- Labels show HP · AP · ammo on each unit in combat
- Enemies also spend AP (move in, shoot, reload)
- Victory returns you to the sprite overworld

NEXT LEARNING STEPS
-------------------
1. Tweak max_ap / cost_* on player_unit.tscn or enemy_unit.tscn
2. Open resources/encounters/enc_dock_ambush.tres — change enemy_count
3. Swap PNGs in assets/sprites/ for your pixel art
4. Read docs/ARCHITECTURE.md before adding systems
