================================================================================
  VEIL OPS — BEGINNER GUIDE (Godot 4)
================================================================================

1. Install Godot 4.3+ from https://godotengine.org
2. Godot → Import → select this folder (project.godot)
3. Press F5 (Play). Main scene should be scenes/main.tscn

CONTROLS
--------
Overworld:
  WASD                    move between sectors
  LMB (click node)        select + accept mission brief
  RMB                     start contact → combat

Combat:
  WASD                    move operative (your turn)
  Mouse                   look / aim (cursor captured)
  LMB                     shoot
  RMB                     end turn
  Esc                     free mouse cursor

WHAT YOU SHOULD SEE
-------------------
- Three overworld nodes on a dark plate
- Log panel bottom-left
- Enter combat → OTS camera + mouse look
- 5 enemies in waves of 2 (Dock Ambush)
- Victory returns you to overworld

NEXT LEARNING STEPS
-------------------
1. Open resources/encounters/enc_dock_ambush.tres — change enemy_count
2. Duplicate a node on the overworld scene
3. Import a Tripo GLB under assets/ and parent it under player_unit.tscn
4. Read docs/ARCHITECTURE.md before adding systems
