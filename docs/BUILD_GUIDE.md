# Veil Ops — Build Guide (short)

Prefer the **interactive slide deck** in Cursor: *Veil Ops Build Guide*.

This page is a scannable summary. Full checklist: `HOW_TO_BUILD.txt`.

## Tools

| Tool | Why |
|------|-----|
| **Godot 4.3+** | Engine (required) |
| **Cursor / ChatGPT** | Step-by-step tutor |
| **Tripo** | Characters / props (GLB) |
| **Cascadeur** | Simple anim later |
| **Kenney / Freesound / OGA** | Free SFX & UI |

Skip Unreal / Maya / mocap for now.

## First run

1. Install Godot → Import this folder → **F5**
2. **Overworld:** WASD move · LMB accept brief · RMB start combat
3. **Combat:** WASD move · Mouse look · LMB shoot · RMB end turn · Esc free cursor

## Build order

| Phase | Focus | Stop when |
|-------|--------|-----------|
| **A** | Own the scaffold (tweak waves, duplicate nodes) | You know where files live |
| **B** | Combat readability (highlight, damage numbers, camera) | Turns are obvious |
| **C** | Brief → fight → debrief | Full op without opening editor mid-run |
| **D** | Tripo art | Screenshots look like the fantasy |
| **E** | Cover / positioning | Standing in open hurts |
| **F** | Small campaign (6–10 missions) | ~30–45 min playthrough |
| **G** | Polish + export | Only after F is fun |

## This week

Install Godot → Play the scaffold → **Phase A only**.
