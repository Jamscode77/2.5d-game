# Frame data assets

Create `UMFFrameDefinition` assets here in the editor, e.g.:

- `DA_Frame_Scout` — light, high boost, low hull
- `DA_Frame_Line` — balanced starter
- `DA_Frame_Heavy` — slow, high hull, high heat capacity

Set `FrameId` to match `UMFGameSettings.DefaultPlayerFrameId` (`MF_Frame_Scout` by default).
